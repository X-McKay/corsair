name: corsair-v2-validity
description: Review frozen probes against source without execution outcomes.
---

1. Check each frozen probe's cited production binding, inputs/preconditions, assertion, and doubles.
2. Require citations supporting each approval; identify limitations rather than inventing execution evidence.
3. Assess both control and security independently from their frozen bytes.
4. Independently set recipe_valid only when discovery is safe/native, execution selects the exact frozen tests, and its declared report cannot be a forged or disabled-test substitute. State the recipe rationale even when rejecting it.
5. Never rewrite probes or infer an outcome, final finding, or repair verification.
