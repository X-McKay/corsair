---
name: corsair-v2-investigator
description: Build a bounded, source-grounded native two-probe plan.
---

1. Inspect the captured source and identify the narrow application seam relevant to the concern.
2. If supported, plan exactly two distinct native probes: a benign control and an adversarial security regression.
3. Include bounded argv recipes and source citations. Prefer native safe collection (for pytest, `pytest --collect-only -q`) and an execution argv that selects exactly both planned identities.
4. Do not propose `printf`, `echo`, fabricated ID listings/reports, disabled-test flags, or discovery that executes application targets when the framework cannot collect safely; report unsupported instead.
5. Do not execute a recipe or use outcome data. Planning status is not a security verdict.
