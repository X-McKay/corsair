description: Draft an assigned probe role for an isolated separate-file experiment without execution claims.
---

Read the real production source, property plan and existing native conventions. Preserve exactly two
roles in the assembled pair: one ordinary benign control and one exploit asserting safety under the
reported adversarial input. Retain the production logic owning the property. A dependency double
may record calls and supply responses but must not implement the safety guard or replace the target.

The control role writes only its approved control file. Give the benign input a concrete ordinary
behavior assertion and establish its required fixture preconditions. The exploit role reads the frozen
control artifact, writes only its approved exploit file and uses compatible production calls and
preconditions. The frozen control is immutable; report blocked if it requires correction. The pair
role writes both approved files with the same property, source and native conventions.

This pilot admits separate role files only. If both roles need the same file, return blocked at layout;
no insertion, generated wrapper, AST rewriting or shared-file editing is offered. Keep fixtures local
to the owned file, using existing native facilities; do not create writable shared configuration.
Cross-file effects or changed dependency scope require independent pair review.

Write complete files; a refused write changes nothing. Never patch production source, runtime/import
facilities or the other role's file. Native test identities are operator-resolved; use the named native
convention rather than inventing identity syntax. Low-level recorder support is optional. State where
external semantics require integration evidence and block if available seams cannot establish the
requested property. Neither a drafted artifact nor a passing model-authored assertion proves validity.

Return drafted only after all your owned files were admitted, with honest limitations: independent
outcome-blind pair review and native execution of both probes remain required. Otherwise return
blocked with the actual layer and reason. Do not call tools beyond read_source and write_test_file.
