# Candidate diagnostics pending human review

This directory holds AI-authored candidate diagnostics pending human review. Candidate records are not human-labelled, held-out, promoted, or population baselines, and provide no accuracy, false-positive, security-clearance, native-execution, Docker, Temporal, or production-readiness evidence. Any external oracle files stay frozen for evaluator comparison only and never enter agent inputs.

Promotion requires independent human labels, family-grouped held-out cohorts, explicit configuration identities, repeated actual evaluations, and a new sanitized record.
