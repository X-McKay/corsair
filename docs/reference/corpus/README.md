# Corpus surveys

One page per language surveys that language's evaluation-corpus rows against the [extension bar](../../guides/extensions.md) and names the rows a recipe is qualified on; the dataset beside it is that language's frozen chain dataset. A survey is a planning record, not a support claim: [platforms](../platforms.md) owns the qualification boundary.
