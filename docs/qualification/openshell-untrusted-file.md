## Native capability and scope

The concrete need is one small generated report, treated as opaque untrusted bytes. Primary references: [pinned Python SDK](https://github.com/NVIDIA/OpenShell/blob/e1f3c82caa3ed3b65de22889ae7ef32a774878ef/python/openshell/sandbox.py), [native CLI archive implementation](https://github.com/NVIDIA/OpenShell/blob/e1f3c82caa3ed3b65de22889ae7ef32a774878ef/crates/openshell-cli/src/ssh.rs) and [server shell/environment setup](https://github.com/NVIDIA/OpenShell/blob/e1f3c82caa3ed3b65de22889ae7ef32a774878ef/crates/openshell-server/src/grpc/sandbox.rs). [The dedicated case](../../tests/qualification/test_untrusted_file.py) composes the supported raw `ExecChunk.data` path in existing OpenShellExecution with existing LocalArtifacts. Final SDK ExecResult text replaces invalid UTF-8 and is unsuitable for binary files. Native CLI download still unpacks an unbounded archive before validating the expected file; no archive download/extraction, transfer API, parser, runner, raw-RPC client or retry framework is added. The recipe is qualification-only, with no production consumer or agent integration.

One literal direct basename is selected beneath an original operator-owned private UUID directory in an inert exclusive sandbox. Trusted inline Python uses `-I -S -B`; no workload script or module is imported. Linux O_PATH/no-follow descriptors bind the original /tmp parent, root and file. Regular type, single link, owner, size and expected inode/stamps are admitted before I/O. The reader reopens that held regular inode through its internally derived /proc/self/fd link, reads at most 4097 bytes into a bounded buffer and checks original/current entry and root/parent identities before emitting at most 4096 raw stdout bytes. No content is parsed or executed on the host. Observed replacement/change refuses collection; equal before/after stamps do not prove an atomic snapshot or detect every transient write.

The file cap follows the existing combined 4096-byte execution output limit. Native execution 2s, host deadline 20s, host worker 512MiB/one CPU/glibc 2.39/two arenas, workload 512Mi/one CPU, policy/TLS/kernel and runtime pins are unchanged. /proc reading was already permitted; actual hard-Landlock descriptor reopening must pass without fallback. No active workload or concurrent writer is admitted.

Only acknowledged terminal exit 0, confirmed original worker reap, exact fixture bytes and protected original-handle intent/result receipts permit immutable artifact publication. Nonzero/partial/unknown execution never publishes or replays. Operator-frozen command/root/file/image/runtime/policy/limits bindings are recorded separately from raw output. Artifact SHA256 names contain no workload path; immutability binds captured bytes, not their semantic trust.
