# Immutable local source and artifact qualification

The independent Milestone2 local storage/source slice passed two actual-host matrices under byte-identical source-v3. Native OpenShell application transfers remain **blocked** by [ISSUE-0006](../development/issues/ISSUE-0006-native-transfer-retry-admission.md); no transfer adapter or live upload/download was dispatched. This report admits a single operator-owned local root and complete offline bare Git repository, not sandbox integration, remote storage or the full milestone. See [SPEC-0012](../development/specs/SPEC-0012-immutable-source-artifacts.md) and [PLAN-0014](../development/plans/PLAN-0014-immutable-source-artifacts.md).

## Qualified boundary

`LocalArtifacts` uses SHA256/size references, bounded exact bytes, a user-owned0700 absolute root anchored by an open directory FD, exclusive0600 temporary creation, file fsync, mode0400 objects, atomic hard-link publication without replacement, and directory fsync. Existing objects must pass type/owner/mode/size/digest validation. Temporary removal checks the original device/inode. A failed publication retains its reference, temporary name/original identity and durability/publication uncertainty; unconfirmed cleanup remains visible. Logical immutability does not prevent the trusted host operator changing a file; digest-checked reads detect corruption. Do not mount this authoritative root into workloads.

`GitSource` uses pinned native Git/prlimit over an operator-controlled complete private bare SHA1 repository. It rejects partial/promisor and shallow sources. Native fsck --strict checks object integrity including trees; raw cat-file and NUL-delimited ls-tree select only regular100644/100755 UTF8 canonical relative paths. No checkout, archive, filters, export substitution, hooks or remote acquisition. Replacement objects and inherited Git configuration/environment are disabled, as are native network protocols. Git commit/blob hashes, byte limits and SHA256 artifacts are checked; the canonical version1 manifest binds commit/tree/path/mode/blob/reference identities. Source intent/result journals are protected and exclusive by operation UUID; reuse is refused before native dispatch. Failures retain partial admitted references and native stderr/exit/PID/reaping observations. The operator-controlled repository configuration is a trust prerequisite, not arbitrary workload input.

Selected actual host: Linux amd64, kernel6.14.0-37-generic, Python3.12.13, Git2.43.0 SHA2562a8c18fbf43da9f692d75474c72bea9dfd796c260b0f3dfe456376abc3bbd668, util-linux prlimit2.39.3 SHA25617064f67e650d6152a6902b013aab496b54c87587c8eea6f5023aafee6154069. Native stat filesystem label is ext2/ext3; no more specific filesystem subtype is inferred. Operator resource controls: artifact object4MiB; source128files/1MiB per blob/4MiB aggregate; native child hard AS512MiB/CPU10s; native pipe/capture command budget20s plus up to2s direct-child reaping. Stdout/tree/commit/stderr are separately bounded. Filesystem writes/fsync are synchronous: the native command deadline is not a hard filesystem-I/O deadline. Disk stalls, power-loss durability and helper descendants are unqualified. Budgets are local controls, not upstream SLOs or universal performance claims.
