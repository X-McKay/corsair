## Decisions and next action

Decided: per-dimension token counts are admitted only on nonzero evidence because the SDK keeps no field presence after mapping and durable payloads serialize every field, so an explicitly reported zero is retained as unknown rather than risk a false zero (PR #21 review item 2). The response cap became the typed `response_token_limit` configuration field so no run-level model settings remain. `InlineDefsJsonSchemaTransformer` stays an explicit override because `VLLMProvider` supplies it only for some model families; the implementer's mock-transport probe found request bytes unchanged. `usage_reported` is derived from `result.new_messages()`. The model-key admission check against the durability registry lives in the test support module because the capability exposes its registry privately. Fixture ids are excluded from the prompt but not renamed to opaque values (deferred; they remain in host-side receipt names). Bool and float budget values are refused in direct mode only; the durable payload converter coerces lax JSON before admission, and the ceiling remains the effective guard. The evaluation CLI needs `PYTHONPATH=src:.` outside pytest, as PLAN-0016 recorded. The tool retry budget of zero means an invented tool ends the run; such attempts are counted in the attempt receipt, and the evaluator only confirms the count for completed cases.
