# Independent implementation review remediation

A read-only independent review identified five material gaps after the first full passing suite. Each was fixed rather than waived.

1. **Role-prefixed oracle admission:** Source admission now rejects oracle/truth filename tokens, including `producer-oracle.json`, `auditor_oracle.json` and `Ground-Truth.yaml`. Three source-boundary regressions prove these cannot enter the producer snapshot. This is a known-oracle filename policy, not a general embedded-secret detector.
2. **Synthetic saved positives passing the scorer:** Saved scoring requires the actual immutable operation record, bundle, admitted `PreparedCase` receipt, source blob and both raw role receipts. It reuses the runtime's native validator and pure verdict rules rather than copying a weaker evidence predicate. Fixed-revision receipts are explicitly separate. Regressions reject both nonexistent and merely plausible synthetic artifact references. The genuine CLI frozen-batch test supplies actual Docker-native evidence through real Temporal and ADK.
3. **Unknown usage becoming zero:** Aggregates return null when any row is unavailable or its call usage is missing. An interrupted agent episode also marks final usage incomplete: known completed rounds remain available but total calls/tokens/time are unknown, never free zero-cost execution. Focused regressions cover both paths.
4. **Completed producer rounds lost on later failure:** The workflow appends each producer round immediately and updates it after evidence/audit completion. Real Temporal tests fail evidence and audit activities and verify the completed proposal/usage and final result remain durable.
5. **Floating trusted base image:** The native Dockerfile pins the Python base registry digest observed during qualification, alongside exact pytest/coverage direct dependencies. Image rebuilds are explicit and require conformance reruns; each run still records its resolved native image identity. This is not a bit-for-bit reproducibility promise for unpinned transitive package artifacts.

Further integration testing also caught and fixed native Temporal cancellation classification, scratch tmpfs ownership for uid 1000, and thread-originated heartbeats. These were not simulated away: the complete real Docker/Temporal/ADK scripted composition and actual CLI batch were rerun.

The review accepted the documented hostile in-process observer limit as an explicit pilot boundary. Production risk qualification, hostile-target attestation, arbitrary probes/builds, multi-language recipes and population-level model accuracy remain unimplemented—not implied by a passing integration suite.
