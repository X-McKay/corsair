# Pilot risk assessment

The canonical executable risk assessment is [packaged with Corsair](../../src/corsair/runtime/risk.md) so the built wheel contains it and each capability manifest records its digest. It names the owner, deployment class, admitted capabilities, correlated semantic failures, runtime/evidence distinction, credential boundaries and explicit non-production qualification limits.

Do not duplicate or silently drift its content here. New recipes, runtime capabilities, provider models, team publication, hostile-source admission or deployment risk require revising that canonical assessment and rerunning affected tests/evaluations.
